= TanStack Table Setup

== Warum TanStack Table?

**TanStack Table** ist eine headless Tabellen-Bibliothek für React.
Im Vergleich zu fertigen Tabellen-Komponenten überlässt sie das Rendering vollständig dem Entwickler und liefert dafür typsichere APIs für Sortierung, Filterung und Paginierung –
ohne eigene Styles oder DOM-Struktur vorzuschreiben.

== Installation

[source,bash]
----
npm install @tanstack/react-table
----

== Spalten definieren

Spalten werden einmalig außerhalb der Komponente mit dem `columnHelper` definiert.
`columnHelper.accessor` erzeugt eine typsichere Spalte für ein Datenfeld;
`columnHelper.display` erzeugt eine berechnete Spalte ohne direkten Datenzugriff (z. B. für Aktionen).

== Tabelle rendern

`flexRender` rendert Header und Zellen anhand der Spaltendefinition.
Über `header.column.getToggleSortingHandler()` wird Sortierung per Klick auf den Spalten-Header ausgelöst.
Ein Suchfeld bindet sich an `globalFilter` und filtert alle Spalten gleichzeitig.
