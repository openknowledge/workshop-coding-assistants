= TanStack Router Setup

== Warum TanStack Router?

**TanStack Router** ist ein typsicherer Client-Side-Router für React.
Im Vergleich zu React Router bietet er vollständige TypeScript-Integration mit automatischer Typinferenz für Routen, Parameter und Suchanfragen,
sodass Fehler schon zur Kompilierzeit erkannt werden.

== Installation

[source,bash]
----
npm install @tanstack/react-router
----

== Ordnerstruktur

Die Routen werden unter `src/routes/` abgelegt.
Jede Datei definiert eine Route mit `createRoute` oder `createRootRoute`.

[source]
----
src/
  routes/
    root.tsx              # Root-Layout-Route
    index.tsx             # Redirect von / nach /customers
    customers/
      index.tsx           # Kundenliste  (/customers)
      editCustomer.tsx    # Kundendetail (/customers/$customerId)
----
